API Endpoints

GET /api/news
Fetch latest news articles with pagination, date filtering, and source query parameters.
GET /api/search?q={query}
Perform full-text search with relevance scoring on titles and content.
GET /api/news/:slug
Extract full article content and media metadata for a specific article.
GET /api/rss
Generate standardized RSS 2.0 XML feed for external readers.
